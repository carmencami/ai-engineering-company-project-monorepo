# agents/_template no es código listo para copiar

## Alcance

Al crear un agente nuevo en `agents/`.

## Justificación

`agents/_template/README.es.md` promete código, configuración y tests. En disco puede haber un `agent.py` vacío; no hay implementación ni tests ejecutables.

## Guía

- Crea `agents/<nombre-del-agente>/` con su propio README.
- No copies `agent.py` vacío creyendo que el agente ya funciona.
- Cuando exista código de agente, pon los tests en esa misma subcarpeta.
