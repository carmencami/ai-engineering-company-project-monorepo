# Toda skill lleva SKILL.md

## Alcance

Al crear o editar carpetas dentro de `skills/`.

## Justificación

`skills/README.es.md` describe cada skill como carpeta con `SKILL.md`. `skills/data-analysis/` tenía scripts y recursos, pero no `SKILL.md`.

## Guía

- Nueva skill = `skills/<nombre>/SKILL.md` (cuándo usarla, inputs, outputs).
- Scripts opcionales en `scripts/`; notas en `resources/`.
- No dejes una skill solo con un `.py` suelto.
