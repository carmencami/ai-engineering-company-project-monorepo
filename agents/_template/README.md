# `agents/_template` folder

This folder is a **base template** for creating new agents under `agents/`. There may be an empty `agent.py` plus READMEs under `tests/`: **there is no implementation or runnable tests to copy**. When an implementation exists, it should include that minimal structure so new agents start from a shared standard.

- **Main purpose**: speed up agent creation and keep consistency (structure, conventions, and testing) across the monorepo.
- **Recommendation**: when you add a new agent, copy/adapt this template and document what changed (goal, tools, prompts, memory, evaluations, and tests).
